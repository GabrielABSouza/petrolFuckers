# Briefing — Hackathon E+ Transição Energética

## Tema

> "Transforme dados em decisões para acelerar a transição energética do Brasil."

Desafio central: **aprimorar a Plataforma Interativa de Descarbonização (PID)** — hub digital do Instituto E+ Transição Energética que conecta planejamento industrial verde a dados de infraestrutura.

## Formato

Híbrido. Presencial em São Paulo: WeWork, Av. das Nações Unidas 14261, 24º andar. Online via Discord.

## Equipe

- Mínimo 3, máximo 5 membros.
- Mentores disponíveis com expertise em energia/clima.

## Trilhas (3 caminhos de desenvolvimento)

1. **User Experience (UX)** — interface, navegação, descoberta de dados, storytelling visual da PID.
2. **Análise & Apoio à Decisão** — novos insights, modelos analíticos, indicadores derivados sobre os dados existentes.
3. **Aplicação Prática** — caso de uso concreto (investidor, gestor público, indústria) sobre a PID.

> **Não é obrigatório escolher uma só** — confirmar com mentor se a entrega pode atravessar trilhas.

## Os 4 pilares (declarados pelo evento)

1. Usabilidade
2. Apoio à decisão
3. Aplicação prática
4. Adoção / escala

## Critérios de avaliação

- Criatividade / inovação
- Aplicabilidade prática
- Uso inteligente de dados
- Potencial de impacto real
- Escalabilidade
